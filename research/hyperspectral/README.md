# 高光谱全领域调研

检索截止日期：2026-10-08。事实使用 `../../src/data/catalog.json`；候选、逐篇决定、证据和覆盖使用本目录。三维专题的 `../survey.json` 保持独立范围；其二维排除决定只用于原专题，不能继承到总库。

## 数据与范围

`collections` 明确保存 `hs3d` 与 `hyperspectral` 成员关系。新普通高光谱论文只写 `hyperspectral`，不写三维 `track` 或 `scope`。原 214 篇成员和出版事实在 `legacy-topic-baseline.json` 留有迁移前快照；校验对比成员、题名、作者、版本年份、场所、分类、范围、链接、DOI 和引用，防止总库影响三维统计。

总库的二维高光谱成像、处理、学习及应用均正常收录。多光谱或基础工作需要明确关系证据，记录 `library.relation` 与 `relationNote`；不能因 spectral 字样自动收录。图拉普拉斯谱、纯频域和泛指 broad-spectrum 的论文需逐篇排除。

`libraryCategories` 是阅读中形成的稳定 ID 标签，维度为任务、方法或应用；定义、证据条目、暂定状态和历史保留在目录。新增论文可 `categoryIds: []`，并标为 `classificationStatus: pending`。改名保留 ID；合并或拆分在 `history` 记录日期、理由和目标 ID，再逐篇复核。

`library` 分别记录阅读进度、核验状态、研究问题、数据集、实验设置、结论、局限、数据入口、证据、版本和方法族。未知用“待核验”；摘要中的性能声明标为作者报告。PDF 局部方法图阅读不等于全文阅读。旧专题成员的总库阅读进度先标待核验，随后逐篇补充；现有笔记和原图保持原来源。

## 检索矩阵与审计

[coverage.md](coverage.md) 为截至日期的场所/年份表，由 `survey.json` 生成。矩阵以场所、年份、关键词组为轴；未列年度/组默认 `not_searched`。从最早可用目录补查至截止日期；目前未确认各场所早期目录边界，不将未检索或无法访问的年代视为不存在论文。

当前执行命令：

```bash
python research/hyperspectral/discover.py CVPR 2022
python research/hyperspectral/discover.py NeurIPS 2023
python research/hyperspectral/crossref-inventory.py "Optics Letters" 0146-9592 2007
python research/hyperspectral/coverage.py
npm run validate
npm run build
```

目录扫描存每个题名、官方链接、原网页 SHA-256、实际获取时间和分页方式。当前标题关键词为 hyperspectral、multispectral、multi-spectral、spectral、spectrum。仅完成该组题名扫描，不代表其他任务词、全量摘要或引用链完成。其他场所、年份、关键词组在 `venuePlan` 与 `matrixDefinition` 继续推进。重复扫描保留已审决定；失败记录原因，继续可访问来源；已有成功证据不会被一次重试失败覆盖。

每个候选记录 `searchId`、`decision`、理由、核验日期、证据路径和收录 ID。`included`、`excluded`、`duplicate`、`pending` 四种决定均留痕。仅发现题名的候选不会自动进入网站。按 DOI、arXiv ID、规范化题名与作者交叉去重；正式版和预印本以 `versions` 关联，`methodFamilyId` 标识方法族。未经确认的版本号、首次提交和更新日期明确记为待核验；不混入会议版实验事实。

`crossref-inventory.py` 逐游标获取一个 ISSN 的登记出版日期年度集合，要求不同 DOI 数与稳定的登记总数一致；保存各页实际时间、条数和响应哈希；`hashInput` 区分原 HTTP 字节与重放时保存的 JSON 响应快照。它是出版社注册到 Crossref 的元数据集合，不能替代出版社全部卷期目录；漏登、日期变化或线上/卷期年份差异仍需交叉核验。命中词目前为 hyperspectral、multispectral、spectral imaging、coded aperture、compressive imaging、compressive spectral。`--response-files` 可重放已经保存的 API 响应；未审决定不会被重放覆盖。

版本 DOI 可以显式写 `versions[].doi`，也会从 doi.org 版本 URL 参与跨条目去重。校验包含前序会议 DOI 与期刊条目版本 URL 相撞的反例：必须有明确且相同的方法族才能保留关联条目。未获得的实验内容继续按版本分别留为未知。

## 每批闭环

1. 选择尚未覆盖的场所、年份和关键词组，记录目录或查询与全部分页范围。
2. 获取候选原始摘要，逐篇判断光学高光谱对象和关系，保存官方证据快照。
3. 对比全库 DOI、arXiv ID、题名及作者，关联版本；记录收录、排除、待核验与理由。
4. 新增事实进入目录，同时检索原文框架图。按 `../figures.md` 保存图号、页码、来源、裁切和校验和；失败则保存真实原因。
5. 依据已读摘要或全文赋予暂定标签，使用独立入口验证展示。检查、更新上下文、本地提交。
6. 在 `batches` 更新本批新增、更新、去重、排除、分类变化和缺口，再生成覆盖表，继续下一检索单元。
