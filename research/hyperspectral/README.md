# 高光谱论文调研

更新：2026-10-13。当前目录419条，三维专题126条。当前收录范围与历史检索覆盖分开记录，尚未声称作者全集或全领域已收齐。

## 收录范围与来源

普通总库仅收直接研究高光谱采集、成像、重建、处理、学习及应用的论文，来源限项目明确的顶会顶刊白名单和arXiv。直接处理或重建高光谱数据的RGB/多光谱融合可以收录；纯多光谱、泛基础关联及只有spectral字样的工作不收录。

具体白名单、出版名称别名与保护ID维护在 [collection-policy.json](../../src/data/collection-policy.json)。这是项目采用的明确口径，不宣称有统一的跨领域排名。白名单包含CVPR、ICCV、ECCV、NeurIPS、ICML、ICLR、AAAI、IJCAI、ACM MM、SIGGRAPH及SIGGRAPH Asia；期刊涵盖TPAMI、IJCV、TIP、TOG、TGRS、RSE、ISPRS JPRS、Pattern Recognition、Information Fusion、Science China Information Sciences和文件列出的主要光学期刊。WHISPERS、IGARSS、ICIP、普通会议、书籍章节等不作普通总库来源；JSTARS、GRSL、TCI当前不在普通总库白名单。

用户要求保留周峻老师既有181条直接高光谱，不因出版来源而删除；101条为白名单外来源例外。7条旧多光谱关联（含1条会议摘要）已移除，作者例外仅放宽来源。身份、覆盖、待核事项与证据入口见 [周峻专项](jun-zhou.md)。不能因姓名相同而自动获得作者例外。

## 事实与资料

唯一论文事实库是 [catalog.json](../../src/data/catalog.json)。`collections`保存三维专题与总库成员关系；`library`记录分类、关系、阅读、实验、证据、版本与方法族。分类确认不等于阅读全文。新普通高光谱条目不添加三维方向元数据。

能免费取得PDF、正文、框架图及作者公开材料时，必须获取并整理可核验的输入输出、方法、框架与实验信息。付费全文先检查arXiv、作者主页及机构公开版本；无免费版本或确实不可获取时保留摘要和访问限制，相应细节留白或注明未获取，不推测补齐，也不反复追索付费正文。性能复现不是本阶段要求。

页面的阅读深度与资料状态独立筛选。资料状态依据既有正文、原图和访问证据；只有PDF链接不表示已取得正文，原图来源受限不自动表示全文付费。可获取但未整理的信息仍作为资料待办。

分类标签的定义、暂定状态和逐篇证据保存在目录，不能为方便展示改写论文事实。任务分组维护在 `src/library-groups.ts`；新增任务标签须同步分组。组计数按论文去重，组内细标签支持多选并集、搜索和单项移除，方法与应用默认折叠。

## 覆盖与历史

[coverage.md](coverage.md)由 `survey.json`生成，当前矩阵仅包含白名单来源。指定题名词或摘要词扫描完成，不等于年度或领域全量完成。未检索年份不推定为零篇。旧范围的搜索、候选、批次和缺口保留为历史证据，不作为普通总库的后续目标。

候选记录收录、排除、重复或待核决定及证据。因本次范围调整删除的候选保留原决定与旧ID，并记录范围排除理由，避免残留指向已删论文的活动引用。未来年份、预印本和正式版按实际证据分开；DOI、arXiv ID及题名作者用于去重，方法族用于明确版本关联。

## 维护流程

1. 选择白名单内未覆盖的场所、年份、任务词或摘要检索单元；作者专项先核身份与来源差集。
2. 取得官方或作者原始书目、摘要和可获取材料，逐篇判断直接高光谱范围，保存来源、获取时间、哈希与访问限制。
3. 去重或关联版本，记录候选决定，将有证据支持的事实写入目录；未知细节如实留白。
4. 可获取PDF与框架原图需整理；原图按 [原图维护说明](../figures.md)登记版本、图号、页码、来源和核验状态。
5. 同步分类证据、原图队列和覆盖，运行校验；网站交互修改还需构建与浏览器检查。
6. 更新当前上下文并本地提交，不推送或发布。

```bash
npm run validate

```
