# 高光谱调研独立入口设计

状态：供审阅的设计方案。已确定的需求是独立入口、现有页面仅增加入口、分类随论文调研逐步形成。本轮提供独立交互原型，不修改现有网站页面或文献分类。

## 入口与边界

现有 HS3D Atlas 导航末尾增加「高光谱调研 ↗」文字入口，默认同标签页打开独立页面。桌面直接显示；手机不得依靠悬停，导航可横向滚动且入口保持可达。现有首屏、13 个方向、核心/相关标注、论文列表和时间线继续服务三维专题。

新页面名为「高光谱调研」，副标题为「已调研论文，持续整理」。独立页面指独立地址、布局和筛选状态，仍在同一项目内。建议地址为 `?collection=hyperspectral`；无 collection 的旧链接仍进入三维专题。新页顶部保留「返回三维视觉专题」，往返及浏览器后退恢复各自筛选与阅读位置，详情链接可直接打开。

「全部」仅指本站已调研条目，不表示已穷尽领域论文。现有文献中的多光谱与背景工作仍明确标注，不因进入总库而改称高光谱核心工作。

## 桌面页面

- 顶栏：页面标识、返回三维专题。
- 紧凑标题区：高光谱调研、当前收录数量、待分类数量。不放大幅首屏动画和宣传卡片。
- 左侧约 224 px：全部论文、待分类，以及随调研形成的分类列表。分类较多时支持搜索和折叠；初期不创建空分类。
- 右侧主区：论文搜索；年份范围、出版来源多选、阅读进度；已选条件；匹配数量与排序；单列论文列表。
- 单条论文：简称与完整标题、年份/出版来源/发表状态、一句话研究问题、分类标签、阅读进度、核验提示。框架原图和详细笔记放入详情，减少列表高度。
- 点开论文：桌面右侧详情面板；手机全屏详情。展示研究问题、输入输出、方法、数据与评测、局限、原始来源、代码和框架原图。未知内容显示「待整理」，不生成无来源结论。

视觉沿用现有石墨黑背景、中性正文、低饱和绿色和细分隔线。分类用低强调标签，避免为尚不稳定的分类建立固定色谱。列表优先支持快速扫描与比较，初版不增加第二套时间线。

## 分类随着调研形成

仅固定「全部论文」与「待分类」两个入口。新条目可以先进入待分类，阅读摘要或全文后再赋予有依据的分类。一篇可以有多个分类；待分类是尚无分类的状态，不是一个研究方向。原型中的分类只用于演示交互，不会写入正式数据。

分类由整理者维护，可增加、改名、合并和拆分。分类使用稳定 ID，改名保留链接；合并记录旧 ID 的去向；拆分需逐篇复核。首次出现且边界不清的方向可标为暂定，说明分类依据；不因条目少而强行并入不适合的类别。任务、方法和应用标签可后续分组，但第一版不预设完整层级，也不强制三维专题的 13 类成为总库分类。

同一分类组内多选取并集，年份、来源、关键词等不同条件之间取交集。「全部论文」「待分类」为独立模式，选择具体分类退出待分类模式。分类计数遵守其他筛选条件，排除分类自身条件；多标签论文在全部数量和结果列表中按论文 ID 去重，各分类数量相加可能大于总数。

阅读进度（待阅读、摘要已读、全文已读）、分类状态和来源核验状态分别记录。全文已读不自动代表出版信息或所有实验结论已核验。预印本、已接收和正式发表仍显示各自状态。

## 手机与空状态

手机单列显示；「分类」按钮打开可多选的筛选面板，年份、来源、阅读进度放入「筛选」面板。主区始终保留搜索、当前条件和结果数量，清除单个条件或全部条件都可直接操作。面板关闭后恢复触发按钮焦点。

尚无文献时展示「尚未收录论文」；待分类为空时展示「当前论文均已分类」；筛选无结果时保留筛选控件并提供清除。待分类数量为零时仍保留入口。图像缺失和来源待核验不得导致整条论文不可见。

## 文献与现有专题隔离

文献事实继续以 `src/data/catalog.json` 为来源，每篇保留稳定 ID、原始来源与核验状态。总库分类和专题成员关系使用独立字段或独立索引引用论文 ID；现有 `track`、`scope` 保留三维专题含义。普通高光谱新文献不必拥有三维方向。

正式实现时先明确现有 214 篇的三维专题成员关系，再加入总库新论文。所有旧页面的列表、概况、计数、资源关联和导出都限定在三维专题成员内，不能继续无条件读取全库。新论文只有经范围审核加入三维专题后才影响旧页。现有论文进入总库时不自动把三维 track 转为已确认的总库分类，也不猜测阅读进度。

跨页面重复出现的论文共用详情事实和图片；总库独立保存分类。正式发表与预印本等版本保留关联，不混淆「条目数」与「独立方法数」。

## 交互原型及实施顺序

`docs/hyperspectral-library-prototype.html` 是自包含原型，使用现有目录中 8 篇论文的真实标题和摘要。分类及阅读进度全部是布局演示值，页面顶部明确提示。支持搜索、分类多选、待分类、年份/来源/进度筛选、排序、清除和详情；不读写正式文献，不实现正式跨页状态恢复或分类编辑。

建议先完成入口和独立论文列表，再支持按稳定 ID 维护分类，最后随实际调研增加标签分组、合并拆分和更细的阅读工具。验收重点：旧链接与三维统计保持原义；新增普通高光谱论文不进入三维专题；待分类及多分类去重正确；桌面和手机计数一致；刷新与返回恢复条件；键盘可打开关闭筛选和详情。
