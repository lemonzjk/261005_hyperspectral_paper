# 高光谱调研独立入口设计

状态：供审阅的设计方案。已确定的需求是独立入口、现有页面仅增加入口、分类随论文调研逐步形成。用户已确认复用现有时间轴、论文卡片及样式。三维页面已增加「高光谱调研」入口，当前连接本地设计预览；文献分类尚未迁移。

## 入口与边界

现有 HS3D Atlas 导航末尾增加「高光谱调研 ↗」文字入口，默认同标签页打开独立页面。桌面直接显示；手机不得依靠悬停，导航可横向滚动且入口保持可达。现有首屏、13 个方向、核心/相关标注、论文列表和时间线继续服务三维专题。

新页面名为「高光谱调研」，副标题为「已调研论文，持续整理」。独立页面指独立地址、文献范围和筛选状态；布局、展示组件和基础样式与三维专题共用。建议地址为 `?collection=hyperspectral`；无 collection 的旧链接仍进入三维专题。新页顶部保留「返回三维视觉专题」，往返及浏览器后退恢复各自筛选与阅读位置，详情链接可直接打开。

「全部」仅指本站已调研条目，不表示已穷尽领域论文。现有文献中的多光谱与背景工作仍明确标注，不因进入总库而改称高光谱核心工作。

## 共用页面与样式

新页直接复用现有浏览方式，默认时间轴，可切换论文卡片。顶栏和内容区沿用现有导航、侧栏、搜索、年份范围、出版来源多选及结果计数样式。保留全部论文与待分类入口，其他分类随调研出现。

- 时间轴共用 `ResearchMap`、`TimelineOverview`、`AtlasOverview`，包括大年份主轴、年份分布、吸顶索引、时间顺序切换、按年展开、原图和 SVG 导出。
- 论文卡片共用 `src/PaperCard.tsx`，沿用桌面双列、手机单列和框架图预览。该组件从原页面提取，原页面行为不变。
- 共用 `src/styles.css`、`src/atlas-overview.css`、`src/design-system.css`，修改共享规则后两个入口同步更新。出版筛选直接使用同一个 `PublicationFilter`。
- 详情沿用现有弹窗样式；预览只读展示摘要、原图、输入输出和方法。正式实现再共用详情组件与完整核验记录。
- 原型专用 CSS 仅补独立入口的顶部间距、预览提示和详情原图尺寸，不重复定义时间轴、卡片或筛选样式。

复用的边界是展示组件和设计样式。两边文献集合、分类体系、计数和 URL 筛选状态仍需独立。正式总库分类接入时，将目前组件依赖的三维方向名称、颜色、专题关系和导出文件名改为可传入的展示信息；三维专题继续采用原默认值。新文献不得为了适配组件而虚构一个三维 track。

## 分类随着调研形成

仅固定「全部论文」与「待分类」两个入口。新条目可以先进入待分类，阅读摘要或全文后再赋予有依据的分类。一篇可以有多个分类；待分类是尚无分类的状态，不是一个研究方向。原型中的分类只用于演示交互，不会写入正式数据。

分类由整理者维护，可增加、改名、合并和拆分。分类使用稳定 ID，改名保留链接；合并记录旧 ID 的去向；拆分需逐篇复核。首次出现且边界不清的方向可标为暂定，说明分类依据；不因条目少而强行并入不适合的类别。任务、方法和应用标签可后续分组，但第一版不预设完整层级，也不强制三维专题的 13 类成为总库分类。

同一分类组内多选取并集，年份、来源、关键词等不同条件之间取交集。「全部论文」「待分类」为独立模式，选择具体分类退出待分类模式。分类计数遵守其他筛选条件，排除分类自身条件；多标签论文在全部数量和结果列表中按论文 ID 去重，各分类数量相加可能大于总数。

阅读进度（待阅读、摘要已读、全文已读）、分类状态和来源核验状态分别记录。全文已读不自动代表出版信息或所有实验结论已核验。预印本、已接收和正式发表仍显示各自状态。

## 手机与空状态

手机沿用现有分类下拉、筛选条、时间轴及单列卡片。原型分类单选；正式多分类筛选如有需要，采用两个入口都可使用的共享控件扩展。保持年份、来源、关键词组合筛选与清除操作，复用现有响应式断点及焦点规则。

尚无文献时展示「尚未收录论文」；待分类为空时展示「当前论文均已分类」；筛选无结果时保留筛选控件并提供清除。待分类数量为零时仍保留入口。图像缺失和来源待核验不得导致整条论文不可见。

## 文献与现有专题隔离

文献事实继续以 `src/data/catalog.json` 为来源，每篇保留稳定 ID、原始来源与核验状态。总库分类和专题成员关系使用独立字段或独立索引引用论文 ID；现有 `track`、`scope` 保留三维专题含义。普通高光谱新文献不必拥有三维方向。

正式实现时先明确现有 214 篇的三维专题成员关系，再加入总库新论文。所有旧页面的列表、概况、计数、资源关联和导出都限定在三维专题成员内，不能继续无条件读取全库。新论文只有经范围审核加入三维专题后才影响旧页。现有论文进入总库时不自动把三维 track 转为已确认的总库分类，也不猜测阅读进度。

跨页面重复出现的论文共用详情事实和图片；总库独立保存分类。正式发表与预印本等版本保留关联，不混淆「条目数」与「独立方法数」。

## 交互原型及实施顺序

`docs/hyperspectral-library-prototype.html` 通过同目录 TSX 入口使用真实共享组件与 CSS，由本地 Vite 服务提供。旧页面顶部「高光谱调研」已连接此地址，预览顶部可返回三维专题。预览使用现有目录中 8 篇论文；其方向及核心/相关标签仅代表三维样例，待分类为演示状态，不写入正式数据。总库不预先创建固定分类，不猜测阅读进度。

预览支持时间轴/卡片切换、年份导航与展开、分类、待分类、搜索、年份范围、出版来源多选、清除、详情和 SVG 导出。当前仅支持本地开发服务，不作为已发布的独立入口；不实现正式跨页状态恢复和分类编辑。拟定的正式地址仍为 `?collection=hyperspectral`。

下一步是审阅同样式预览，再完成专题成员隔离及动态分类数据接入。验收重点：修改共享组件或样式后两个入口同步；旧链接与三维统计保持原义；新增普通高光谱论文不进入三维专题；待分类及多分类去重正确；桌面和手机计数一致；刷新与返回恢复条件；键盘可打开关闭筛选和详情。
