# 研究图谱界面设计

## 目标

将原有方向与年代矩阵改为真实年份的纵向阅读时间轴，让方向、年份、论文详情形成明确的阅读路径。维持浅色全宽三维首屏、本地预览与现有筛选功能。

## 参考项目

2026-10-07 阅读了以下开源项目与示例：

- [OpenTimeline](https://github.com/izored/openTimeline)：阅读 README 和 `src/App.tsx`，参考年度分组、主题导航与详情阅读方式。本站采用按年份分组的文档滚动，未复制项目代码或引入其后端、滚动库。
- [vis-timeline](https://github.com/visjs/vis-timeline) 及[官方示例](https://visjs.github.io/vis-timeline/examples/timeline/)：检查其时间轴与分组浏览思路。本站只记录论文年份，没有精确月份；默认采用可直接阅读的年度卡片，完整方向与年份线路图保留为 SVG 导出。
- [PaperFlow](https://github.com/OpenRaiser/PaperFlow)：阅读文献发现工作流与筛选入口说明，参考论文、来源与阅读操作的层次。未接入项目服务，也未声称复现其推荐功能。

本站样式与组件独立实现，不新增依赖，不构造未经核验的引用关系或精确发表日期。

## 实现

- 桌面左侧显示 13 个方向与收录数量，选择方向写入现有 URL 筛选；手机使用方向下拉。
- 搜索、年份范围、出版来源、场景表示集中在内容区域顶部，共同作用于时间轴与论文库。
- 时间轴按实际出现的年份分组，默认从新到旧，支持切换顺序与年份锚点跳转。
- 每年默认展示六篇，沿用同年简称排序，不表示质量排名；可展开单年或全部论文。计数展示该年全部匹配论文数量。
- 卡片显示出版来源、核心/相关研究、接收/预印本状态、方法摘要、方向和已有原图缩略图。缩略图不裁切，论文详情保留原图、归属及来源；缺图不生成替代图。
- 页面使用共同的灰蓝正文、浅绿操作状态、细边框与留白。论文库采用桌面双列与手机单列。
- 年度节点与连线只组织阅读；节点间距不是持续时间，方向分组不表示继承。

## 验证

运行 `npm run validate`、`npm run build`；浏览器核对年度覆盖、单年与全部展开、排序、年份跳转、方向/年份/出版联合筛选、空状态、详情关闭与 URL 恢复、SVG 下载，以及桌面和移动端的页面宽度与原图加载。
