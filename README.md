# HS3D Atlas · 高光谱三维视觉研究图谱

探索高光谱与三维视觉交汇的研究路线、论文与数据资源。

三维专题目前包含 13 个研究方向、126 篇论文与 2 个数据资源入口；独立高光谱总库当前收录 456 篇条目，涵盖计算机视觉、遥感与光学；其中三维专题成员同时保留专题集合关系。系统检索仍在进行，尚未覆盖整个领域。条目记录原始来源、核验日期及待核验信息。

## 本地运行

需要 Node.js 22.12 或更新版本。

```bash
npm ci
npm run dev
```

打开终端中显示的地址。默认端口为 `5173`。

如果项目运行在远程服务器，而浏览器运行在自己的电脑上，需要先转发端口。在 VS Code 远程窗口打开「端口」面板，选择「转发端口」，填写 `5173`，再点击该行的「在浏览器中打开」。以面板显示的本地地址为准；当本机 `5173` 被占用时，转发可能分配其他本地端口。服务监听 `0.0.0.0` 并不等于端口已经转发。

若地址可以连接但页面空白，查看浏览器错误，并运行 `npm run validate` 检查文献方向等数据字段。

```bash
npm run validate
npm run build
npm run preview
```

`validate` 检查文献字段、数据资源关联、来源链接格式及图谱分组是否完整、无重复。`build` 检查 TypeScript 并生成静态网站至 `dist/`。

## 页面功能

- 时间线与论文库支持「全部研究 / 核心研究 / 相关研究」筛选，默认全部。三个选项的数量按其他筛选条件实时计算；选择通过 URL 的 `scope=core` 或 `scope=related` 保存，切换视图和刷新保留，「清除筛选」恢复全部。范围依据现有文献标注，不自动重新分类。
- 三维专题和高光谱总库均支持独立作者筛选：输入姓名或片段，可从当前库的作者候选中补全；忽略大小写和重音，多个姓名词必须属于同一作者。与年份、来源、关键词等条件取交集，URL 的 `author` 参数保留筛选，清除筛选同时重置作者。输入库内已记录的完整作者姓名时，普通搜索和作者筛选均按完整姓名匹配，避免把不同合作者的姓名词拼接或匹配到其他姓名的子串。姓名按库内原始记录显示，不凭首字母推断完整身份。
- 按研究方向、起止年份（包含边界，任一端可不限）、出版来源（期刊／会议）、场景表示筛选；支持关键词搜索。
- 出版来源可同时勾选多个会议、期刊和预印本来源，按组组织，支持简称/出版全名搜索、组全选、清空及逐项移除。多选来源取并集，与年份、研究方向和关键词组合筛选；不选择时显示全部。URL 使用重复的 `venue` 参数，兼容已有单来源链接，刷新保留筛选。
- 默认图谱采用年度纵向时间轴：桌面左侧选择研究方向，右侧以大年份和单列论文组成纵向主轴；手机使用方向下拉与单列论文。上方柱图展示当前筛选下的收录数量（不代表领域发表总量），点击柱图可跳转。吸顶年份索引随滚动高亮当前年份，点击后转移键盘焦点；支持最新/早期优先切换，每年默认展示六篇，可按年展开或展开全部。卡片包含出版来源、接收/预印本/在线先行状态、研究范围、方法摘要与已有框架原图缩略图，点击查看完整详情。所有筛选共同生效，保留年度 SVG 导出；年份间距不表示时长，方向不表示方法继承。设计参考与取舍见 `docs/interface-design.md`。
- 整站采用石墨黑主题与统一的排版、导航和筛选样式；首屏直接铺满视口，去除标题文案、外框和分栏底板，顶部使用全宽实色固定导航（桌面 68px、手机 60px）。默认单幅 850 nm 合成地形，对照和使用说明按需打开；光谱面板可收起，手机默认收起并保留快捷波段。场景底部提供研究图谱入口。支持波长预设、滑块和键盘、表面采样、材料曲线、拖动旋转、复位；地形和曲线均为明确标注的合成示意，不是实测结果。详见 `docs/hero-visual.md`。导航切换会定位到内容起点。论文详情保留出版全名、版本与状态、DOI 和白底框架原图。
- 论文详情、输入与输出、方法笔记、原始来源与 BibTeX。
- 论文详情展示已核验的框架原图，可打开高清图，显示图号、PDF 页码、来源与作者归属。暂未检索、待人工补充和所用版本未发现独立框架图分别标记；收集进度见 [research/figures.md](research/figures.md)。
- 数据资源入口、收录范围和建议阅读顺序。
- URL 保留筛选和选中论文，便于分享；移动端适配、键盘访问与对话框焦点管理。

## 高光谱调研入口

导航中的「高光谱调研」打开 `?collection=hyperspectral`；无 collection 的旧链接进入三维专题。总库复用时间轴、论文卡片、出版筛选和完整详情，通过独立成员关系、分类、计数及 URL 筛选保持范围清晰。两页往返保存各自筛选与阅读位置，分享链接可直接打开详情。

总库按11个主要任务组组织浏览，详细任务、方法和应用标签可展开及搜索；组计数按论文去重，已选标签可逐项移除。支持待分类、多标签并集、年份范围、规范化出版来源多选、来源范围、关键词、阅读进度及独立资料状态筛选。详情记录输入输出、方法、实验待核验字段、证据和版本；BibTeX 与 SVG 导出使用当前总库筛选结果。检索覆盖面板区分指定关键词扫描、主题检索和未检索范围。

截至 2026-10-13，总库456篇，其中443篇分类确认、13篇暂定、0篇待分类；分类审计清单覆盖433篇，现有184个标签按研究任务、方法和应用区分。组内任务标签按当前筛选范围内的论文数降序排列，数量相同保留目录顺序。两页侧栏隐藏当前计数为零的方向或标签；总库的空标签维度和零条目待分类入口也隐藏。已选筛选仍保留，可通过清除筛选恢复。归类以实际输入、输出及既有来源笔记为依据，原阅读进度、实验待核验字段和来源证据分别保留；分类确认不等于阅读全文。逐篇依据保存在 `library.classificationReview`，复核范围及额外原始来源检查见 [分类审计](research/hyperspectral/classification-audit.json)。

两页继续使用同一套布局、核心展示组件与共享样式。总库的分类数据及排序独立，现有补充模块不另做视觉改版；后续优化三维视觉页面的共享 UI 时，同时检查总库同步结果。

总库的检索规则、候选决定、覆盖与后续计划见 [research/hyperspectral/README.md](research/hyperspectral/README.md) 和 [覆盖表](research/hyperspectral/coverage.md)。文献事实仍统一维护在目录中；新普通高光谱条目使用 `collections: ["hyperspectral"]`，分类由 `libraryCategories` 与 `library.categoryIds` 保存。

## 维护文献

2026-10-11清理后，总库保留390条直接高光谱，累计删除367条范围外记录及其152个原图文件；三维专题保留126条，数据资源保留2个。无论文关联的160个标签已移除，其余164个细标签保留原分类证据。删除与名称规范化决定见 [清理审计](research/hyperspectral/catalog-cleanup.json)；原始条目可通过Git历史恢复。

来源范围支持顶会顶刊（白名单）、arXiv预印本和白名单外（周峻专项），与其他筛选取交集，URL通过`publicationScope`保存，导出沿用当前结果。资料状态依据已记录证据显示，不把PDF链接当作已获取正文，也不把原图来源访问受限自动判成全文付费。资料待办以一张主要框架图为目标，不要求补齐其他正文或图片。

后续调研只收录直接高光谱研究，不再新增纯多光谱关联论文。直接处理或重建高光谱数据的RGB/多光谱融合论文仍在范围内。周峻老师既有181条直接高光谱作为作者来源例外保留，其余条目已按当前来源和直接高光谱范围清理。

新调研的出版来源仅限计算机视觉或高光谱领域顶会顶刊，以及arXiv预印本；其他会议、期刊、会议摘要和学位论文不作为普通总库新收录对象；周峻既有181条直接高光谱按用户要求保留，例外仅放宽出版来源。具体白名单和名称别名维护在 [collection-policy.json](src/data/collection-policy.json)，历史场所不自动属于新收录范围。

调研以论文目录完整为优先目标。每篇只找一个可用版本，提取一张最主要的原始框架图；只读取确认作者、高光谱范围和定位该图所需的内容，不逐页阅读全文、不逐版本阅读、不深入整理实验与性能。必要的版本去重依据书目信息完成。官方代码只记录链接，不检查或下载代码。

论文付费时检查常见公开版本；确实无法获取或没有框架图时，保留摘要、来源及访问限制，图可留白，不反复追索。目录覆盖与主框架图获取分别报告；取得一个版本及一张主图后，不再将其他版本、额外图片或实验细节列为待办。历史全文阅读和多图记录仅作为已有资料保留。此标准适用于后续全部论文。

编辑 `src/data/catalog.json`。新增论文需提供来源、版本年份、核验日期和已读证据支持的输入输出与阅读说明；无法获取的内容按上述规则标记，不猜测补齐。图谱根据筛选结果生成时间总览与可导出的年度线路图；导出图同年论文密集时自动增大年份列宽，避免标签重叠；当前只使用核验年份，不推定发表月份。研究方向配置在 `src/tracks.ts`。

研究方向包括采集系统与标定、几何重建、场景表示、材料与逆渲染、三维理解、主动三维成像、光场、光谱全息、光谱 LiDAR、光谱点云构建、跨模态配准和高度辅助融合。选择尚无已核验论文的方向时显示整理中的提示。路线只表示阅读组织，不声明方法继承关系。

导出的 BibTeX 由同一底表生成。后续补齐作者或版本信息时，直接更新条目的 `citation`。

## 在页面上传框架图

使用 `npm run dev -- --port 5173` 启动本地编辑服务，需要 Python 3 和 Pillow（与 `research/figures.py` 的依赖一致）。静态构建及 `npm run preview` 只提供浏览，不显示上传入口。

1. 打开任一论文详情，可直接把本地图片拖入框架图区补充，拖到已有框架图上则替换。也可点击「＋ 补充图片」或「替换此图」，在表单内拖入或选择文件。一次处理一张，拖入后先预览，再点击保存。
2. 选择 PNG、JPG 或 WebP 静态图片，预览后填写图号或名称、HTTPS 来源链接，可补充说明。单图最大 10 MB，宽高至少 100 像素，总像素不超过 2500 万。
3. 点击「保存补充图」或「保存替换」。图片保存到 `public/figures/<paper-id>/`，元数据同步保存到 `src/data/catalog.json` 与 `research/figures.json`，刷新后仍可查看。

补充图片追加到列表；替换图片保留原位置，旧文件不删除，旧图号、来源和核验信息存入「替换历史」。新上传图片默认标记「用户上传 · 待核验」，不会自动继承旧图的核验结论；存在待核验图的论文在续接清单中标记 `needs_review`。重复图片、损坏图片和失效的替换目标会拒绝保存。失败时表单保留，可修正后重试。

上传不会自动创建 Git 提交；整理核验完成后运行 `npm run validate` 并按仓库约定提交。后端检查可运行 `python3 -m unittest discover -s server -p 'test_*.py'`；测试使用临时目录，不修改文献数据。
