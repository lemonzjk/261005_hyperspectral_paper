# HS3D Atlas · 高光谱三维视觉研究图谱

探索高光谱与三维视觉交汇的研究路线、论文与数据资源。

目前包含 13 个研究方向、196 篇论文与 6 个数据资源入口，涵盖计算机视觉、遥感与光学。系统检索仍在进行，尚未覆盖整个领域。条目记录原始来源、核验日期及待核验信息。

## 本地运行

需要 Node.js 22.12 或更新版本。

```bash
npm ci
npm run dev
```

打开终端中显示的地址。默认端口为 `5173`。

如果项目运行在远程服务器，而浏览器运行在自己的电脑上，需要先转发端口。在 VS Code 远程窗口打开「端口」面板，选择「转发端口」，填写 `5173`，再点击该行的「在浏览器中打开」。以面板显示的本地地址为准；当本机 `5173` 被占用时，转发可能分配其他本地端口。服务监听 `0.0.0.0` 并不等于端口已经转发。

若地址可以连接但页面空白，查看浏览器错误，并运行 `npm run validate` 检查文献方向等数据字段。

```bash
npm run validate
npm run build
npm run preview
```

`validate` 检查文献字段、数据资源关联、来源链接格式及图谱分组是否完整、无重复。`build` 检查 TypeScript 并生成静态网站至 `dist/`。

## 页面功能

- 按研究方向、起止年份（包含边界，任一端可不限）、出版来源（期刊／会议）、场景表示筛选；支持关键词搜索。
- 默认「领域图与时间轴」展示紧凑的三列方向索引：采集与空间对齐、重建与场景表示、理解与扩展成像。13 个方向直接显示任务提示与篇数，点击方向定位下方时间轴；省去重复年代格和装饰图。时间轴纵向看方向、横向看年代，每阶段显示最新收录的一篇，标题打开详情，篇数或方向就地展开完整列表。论文简称完整换行，圆点表示核心研究，方点表示相关研究。无需拖拽、缩放或横向滚动，手机纵向浏览。仅保留默认视图与「全部论文」两种阅读方式，并提供年度 SVG 导出；筛选共同生效。阶段等宽不表示时长，排列不表示排名或方法继承。
- 首页采用全宽空间与光谱交互示意，场景下方提供「探索研究时间轴」「浏览论文库」入口：点云可旋转，切换自然色、几何与单波段响应；波长滑块联动表面着色和材料曲线。点击表面或植被／岩石／水体按钮选择曲线。场景与曲线使用明确标注的合成数据，不是实测结果；详见 `docs/hero-visual.md`。论文详情显示出版来源全名、版本年份与状态，存在 DOI 时显示 DOI。
- 论文详情、输入与输出、方法笔记、原始来源与 BibTeX。
- 论文详情展示已核验的框架原图，可打开高清图，显示图号、PDF 页码、来源与作者归属。暂未检索、待人工补充和全文未发现独立框架图分别标记；收集进度见 [research/figures.md](research/figures.md)。
- 数据资源入口、收录范围和建议阅读顺序。
- URL 保留筛选和选中论文，便于分享；移动端适配、键盘访问与对话框焦点管理。

## 维护文献

编辑 `src/data/catalog.json`。新增论文需提供来源、版本年份、核验日期、输入与输出和阅读笔记。图谱根据筛选结果生成时间总览与可导出的年度线路图；导出图同年论文密集时自动增大年份列宽，避免标签重叠；当前只使用核验年份，不推定发表月份。研究方向配置在 `src/tracks.ts`。

研究方向包括采集系统与标定、几何重建、场景表示、材料与逆渲染、三维理解、主动三维成像、光场、光谱全息、光谱 LiDAR、光谱点云构建、跨模态配准和高度辅助融合。选择尚无已核验论文的方向时显示整理中的提示。路线只表示阅读组织，不声明方法继承关系。

导出的 BibTeX 由同一底表生成。后续补齐作者或版本信息时，直接更新条目的 `citation`。

https://lemonzjk.github.io/261005_hyperspectral_paper/
